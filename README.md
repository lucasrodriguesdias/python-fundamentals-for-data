# Prática Python para Dados 🐍📊

Este repositório contém exercícios práticos desenvolvidos em Python com foco em **lógica de programação**, **estruturas de dados** e **conceitos fundamentais para análise de dados**.

O objetivo é consolidar o aprendizado por meio da resolução de problemas envolvendo listas, dicionários, laços de repetição, condicionais e funções built-in do Python.

---

## 📌 Conteúdos abordados

Os exercícios presentes neste repositório trabalham os seguintes temas:

- Estruturas de dados:
  - Listas
  - Dicionários
- Estruturas de controle:
  - `for`
  - `if / elif / else`
- Funções built-in:
  - `sum()`
  - `len()`
  - `max()`
  - `min()`
- Cálculos estatísticos simples:
  - Média
  - Percentual de crescimento
- Manipulação e análise de dados numéricos
- Boas práticas de lógica e organização de código
